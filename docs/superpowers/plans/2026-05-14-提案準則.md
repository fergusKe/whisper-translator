```markdown
## 01 商業定位

> **30 秒摘要：** 定位是你在客戶心智中佔的位置，不是你的自我介紹。定位要夠窄、夠清晰，讓人一聽就知道你解決什麼問題、為什麼找你。

### 核心準則

1. **賣新機會，不賣改善方案** — 「幫你做得更好」沒有吸引力；「帶你進入一個新方法」才有。
2. **心智佔位比功能比較更重要** — 你要搶的不是市場份額，而是客戶心智中的一個位置。
3. **聚焦才有力量** — 越試圖服務所有人，越沒人記得你。定位越窄，說服力越強。
4. **一句話說清楚** — 好的定位可以用一句話表達：「我幫 [誰] 解決 [什麼問題]，用 [什麼方法]。」
5. **定位要和你真實的優勢一致** — 不是找一個聽起來好聽的說法，而是找一個你真的能長期持守的角度。

### 提案 Checklist

- [ ] 你服務的是誰？（越具體越好，不要說「所有人」）
- [ ] 你解決的核心問題是什麼？
- [ ] 你的方法為什麼是「新機會」而不是「更好的方案」？
- [ ] 如果市場上已經有人做類似的事，你跟他們哪裡不一樣？
- [ ] 你能用一句話說清楚你的定位嗎？

---
```

```markdown
## 02 受眾輪廓

> **30 秒摘要：** 不要描述「目標受眾群體」，要描述「一個具體的人」。你的夢幻客戶是最理想的那一個，不是最多的那一群。找到他，為他說話，其他人也會被吸引。

### 核心準則

1. **具體到一個人** — 不是「25-40 歲女性」，而是「35 歲在家帶孩子、想重返職場但不知道從哪裡開始的媽媽」。
2. **描述現狀，不只是人口統計** — 他現在在做什麼？遇到什麼困境？嘗試過什麼方法但失敗了？
3. **描述渴望，不只是痛點** — 他想要的理想狀態是什麼？不只是「解決問題」，而是「解決問題之後的生活」。
4. **描述顧慮** — 他為什麼還沒解決這個問題？什麼讓他猶豫？這些顧慮你的提案要直接回應。
5. **夢幻客戶決定你的說話方式** — 你用什麼詞彙、舉什麼例子、說什麼故事，都應該對「那一個人」最有共鳴。

### 提案 Checklist

- [ ] 你的夢幻客戶現在的生活狀態是什麼？
- [ ] 他遇到的核心問題是什麼？他已經嘗試過哪些方法但還是沒解決？
- [ ] 他最渴望的理想狀態是什麼？（要具體，不只是「成功」或「自由」）
- [ ] 他的主要顧慮是什麼？為什麼他還沒行動？
- [ ] 你的定位（01）和你的夢幻客戶（02）有沒有邏輯一致？
```

```markdown
## 03 競品分析

> **30 秒摘要：** 競品分析不是功能比較表，而是心智地圖。你要找出客戶心中已經有哪些「位置」被佔走了，然後找到一個你可以「唯一」的角度，而不是「更好」的角度。

### 核心準則

1. **競爭發生在心智，不在功能** — 客戶不會比較規格表，他們會問「我應該找誰？」你要搶的是那個答案裡的位置。
2. **找唯一，不找更好** — 「我比別人便宜/快/好」是功能競爭，遲早被複製。「只有我能做到 X」才是真正的護城河。
3. **了解對手的定位，才能差異化** — 競品做什麼不重要，重要的是他們在客戶心中代表什麼，你要佔另一個位置。
4. **品類可以自己創造** — 如果現有品類不利於你，可以重新定義品類，讓自己成為新品類的第一名。
5. **競品分析要定期更新** — 市場心智會變，競品也在移動，固定的分析很快就過期。

### 提案 Checklist

- [ ] 你的主要競品是誰？他們在客戶心中代表什麼？
- [ ] 你和他們最大的差異是什麼？（從客戶角度，不是從你的角度）
- [ ] 你的「唯一性」是什麼？有沒有一個角度是只有你能代表的？
- [ ] 如果客戶不選你，他們通常會選誰？為什麼？
- [ ] 你的定位（01）在競品地圖中，站在哪個位置？

---
```

```markdown
## 04 Offer 提案

> **30 秒摘要：** Offer 不是單一產品，而是一個有層次的價值系統（價值階梯）。從低門檻的免費/低價產品開始，逐步引導到高單價核心產品，每一層都要有清楚的交付物和升級路徑。

### 核心準則

1. **Offer 要有層次（價值階梯）** — 不要只有一個產品。低門檻入口讓人試試看，核心產品才是主要收入，高端產品服務最認真的客戶。
2. **每一層都要說清楚交付物** — 客戶付了錢，他得到什麼？要具體，不能是「你會變更好」，要是「你會拿到 X、學到 Y、完成 Z」。
3. **定價要有邏輯** — 價格不是隨感覺定的，要能說清楚為什麼這個價格對應這個價值。
4. **升級路徑要設計好** — 客戶從哪一層進來？下一步是什麼？如果沒有自然的升級路徑，每次都要重新開發新客戶。
5. **Offer 要先做好，才做流量** — 很多人先衝流量，再想賣什麼。正確順序是先確認 offer 能成交，再放大流量。

### 提案 Checklist

- [ ] 你的價值階梯是什麼？（從最低門檻到最高單價，每層的產品是什麼？）
- [ ] 每一層的交付物是什麼？（具體列出，不能是模糊描述）
- [ ] 每一層的定價是什麼？定價的邏輯是什麼？
- [ ] 客戶如何從一層升級到下一層？升級的觸發點是什麼？
- [ ] 你的核心收入來自哪一層？這一層的成交路徑是否清楚？

---
```

```markdown
## 05 公域內容

> **30 秒摘要：** 公域內容不是為了追蹤數，而是為了吸引對的人。用「議題柱子」讓每一篇內容都有策略性，而不是隨機發文。內容要有清楚的導流方向，讓看到你的人知道下一步去哪裡。

### 核心準則

1. **議題柱子決定你的內容策略** — 先設計 3-5 個核心議題（代表你、吸引夢幻客戶、展現專業），每篇內容都屬於其中一個柱子，不要隨機發文。
2. **吸引對的人，不是最多的人** — 10 個高度匹配的讀者，比 1000 個隨機流量更有價值。內容要有篩選功能。
3. **每篇內容要有導流方向** — 看完這篇文章，你希望讀者做什麼？去哪裡？公域內容的終點是進入你的私域。
4. **內容要展現你的觀點，不只是資訊** — 資訊到處都有，只有你的觀點是唯一的。有立場的內容才有記憶點。
5. **一致性比爆紅更重要** — 持續產出比偶爾的爆款更能建立長期信任與流量。

### 提案 Checklist
```

```markdown
## 06 私域內容

> **30 秒摘要：** 私域不是把人圈起來賣東西，而是建立一個信任系統。先建立關係，先給予價值，才有長期穩定的成交。私域是你真正的資產，不是社群平台的粉絲數。

### 核心準則

1. **私域是信任系統，不是流量池** — 把人圈進來再想怎麼賣，只會讓人感覺被收割。正確邏輯：先建立關係 → 先給予價值 → 自然成交。
2. **三大核心價值觀：慷慨、真誠、許可** — 慷慨給予而不計較、真實表達而不表演、尊重對方的節奏而不強迫。
3. **故事與人設是連結的橋樑** — 人連結的是人，不是產品。你的個人故事、價值觀、日常分享，讓人覺得認識你，才會信任你。
4. **私域護城河** — 如果 Instagram/LINE 今天消失，你還能聯絡到多少人？真正的私域資產是你能直接觸達的人，不是平台上的追蹤數。
5. **不要以推銷為目的** — 每次發私域內容時問自己：這對他們有價值嗎？還是我只是想賣東西？長期推銷只會讓人封鎖你。

### 提案 Checklist

- [ ] 你的私域在哪個平台或媒介？（LINE 群組、電子報、社群等）
- [ ] 你的私域內容計畫是什麼？多久發一次？發什麼類型的內容？
- [ ] 你如何讓公域的人進入你的私域？（入口是什麼？）
- [ ] 你如何在私域中建立信任，而不只是推銷？
- [ ] 如果平台消失，你有辦法聯絡你的私域名單嗎？

---
```

```markdown
## 07 變現閉環

> **30 秒摘要：** 流量是原料，不是收入；產品是零件，不是系統。真正的閉環是讓「內容→私域→成交→回購→升級」彼此扣起來，讓系統自己運轉，而不是你一直在推。

### 核心準則

1. **先檢查閉環是否完整** — 你有流量，但有沒有辦法承接？你有產品，但客戶成交後，下一步是什麼？沒有閉環，只是窮忙。
2. **閉環的完整路徑：** 公域引流 → 私域承接 → 成交 → 回購/升級 → 轉介裂變。每一個環節都要有設計。
3. **要有客戶分層** — 不是每個客戶都在同一個階段。低單價客戶、核心客戶、高端客戶各自要有不同的對應方式和升級路徑。
4. **轉介裂變是最低成本的成長** — 滿意的客戶介紹新客戶，比任何廣告都有效。要主動設計轉介機制，不要等客戶自發。
5. **用長期思維看閉環，不用短期技巧** — 每個決策都問：這個做法三年後還成立嗎？走捷徑的問題遲早會爆開。

### 提案 Checklist

- [ ] 你的完整閉環路徑是什麼？（從陌生人到忠實客戶的每一步）
- [ ] 客戶成交後，下一步是什麼？有沒有回購或升級的設計？
- [ ] 你有沒有設計轉介機制？如何讓滿意的客戶帶來新客戶？
- [ ] 你的客戶分層是什麼？每一層如何往上升級？
- [ ] 整個閉環，哪個環節目前最薄弱？優先補強哪裡？
```
